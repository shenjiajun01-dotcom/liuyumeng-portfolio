# 刘雨朦 · 个人简历与设计作品集

使用 React 19、TypeScript、Vite、Motion 与原生 CSS 构建的响应式个人展示网站。页面素材全部来自工作区提供的简历、证件照和作品集，不使用虚构项目或占位图片。

## 本地运行

建议使用 Node.js 24（本项目已验证的环境）。

```sh
npm install
npm run dev -- --port 5173
```

访问 http://localhost:5173 。若端口被占用，Vite 会输出实际使用的地址。VS Code 中也已配置“预览个人作品集”任务。

## 更新原始素材

根目录保留了用户原始 JPG、PDF 与 PPTX。素材脚本读取根目录对应扩展名的文件，根目录应各保留一份明确的源文件；备份请放入其他目录。

替换源文件后执行：

```sh
npm run inspect:pdf
npm run prepare:assets
npm test
npm run build
```

`inspect:pdf` 输出文字索引和 `.source/overview.jpg` 总览图，便于核对章节。`.source/` 是临时资料，不参与网站运行，也不被测试依赖。

如果 PDF 页数、章节或排版改变，需要同步更新 `src/content.ts` 中的 `pages`、章节印刷页码，素材脚本中的封面裁切参数，以及完整档案所使用的总页数与测试期望。当前总页数固定为已核验的 19 页。

生成脚本不会修改根目录的原始文件。网页文档副本会设置为可写，避免 Windows 只读源文件在重复构建时触发 `EPERM`。

## 性能策略

- 首屏图片预加载，其余图片使用浏览器懒加载和异步解码。
- PDF 跨页预先转换为 WebP；全页阅读和缩略图使用不同规格。
- 阅读器采用动态导入，只在打开作品时载入组件。
- **首页与图片预览不请求约 27 MB 的完整 PDF**，只有主动打开或下载原文件时才访问它。
- 字体随站点部署，使用 WOFF2、字符子集及 `font-display: swap`，不依赖外部字体服务。
- 仅构建时使用 PDF.js 与 Canvas，它们不会进入前端运行包。

## 构建与发布

```sh
npm run build
npm run preview -- --port 4173
```

生产产物位于 `dist/`，可发布到支持静态站点的服务。无后端、数据库或环境变量依赖。

站点已通过 GitHub Actions 自动部署到 GitHub Pages：

- 线上地址：<https://shenjiajun01-dotcom.github.io/liuyumeng-portfolio/>
- 工作流：`.github/workflows/deploy.yml`
- 推送到 `main` 分支即触发重新构建与部署，访问地址保持不变。

项目站点位于 `/liuyumeng-portfolio/` 子路径下，因此构建时 Vite `base` 会自动指向该路径（本地开发仍使用根路径），源码中的静态资源地址统一以 `import.meta.env.BASE_URL` 为前缀拼接。
